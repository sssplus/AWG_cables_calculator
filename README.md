## Run this snapshot locally

No build tools required — it's plain HTML/CSS/JS:

```bash
git clone https://github.com/sssplus/AWG_cables_calculator.git
cd AWG_cables_calculator
python3 -m http.server 8000
# open http://localhost:8000
```
